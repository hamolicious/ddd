# Delete permanently

Left open from `dev-docs/resolved/SYNC-DECISIONS.md` §4.

There is no "Delete permanently" action: a note in Trash is purged only after 30 days.
Should people be able to empty Trash (or delete one note for good) sooner?

- **A. No.** Trash is the safety net; 30 days stays the only way out.
- **B. "Delete permanently" per note, in Trash**, behind an "are you sure" (context-menu
  `confirm`). Purges now; a device holding unsent edits to it still gets them back as a new
  note (§4).
- **C. B, plus "Empty Trash"** for everything in it.
